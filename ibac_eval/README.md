# IBAC 机制级仿真评估（论文 §7 实验协议的实现）

本目录把论文《面向自主智能体的任务-意图绑定访问控制与可验证运行时控制》第 7 节的实验设计实现为一个**可复现的
Python 仿真实验**：B0–B4 五组控制面对照、攻击场景 A–H、合法任务套件、
UAR/ABR/LCR 等多维指标、消融与敏感性分析、H1–H5 配对假设检验。

```bash
python3 run_experiments.py            # 全量运行（约 1 分钟）
python3 run_experiments.py --quick    # 快速冒烟（约 10 秒）
python3 run_experiments.py --seeds 500 # 增大样本量
```

结果输出至 `results/`：`summary.md`（中文结果报告）、`trials_*.csv`（每次试验
原始数据）、`agg_*.csv`（聚合表）、`plots/fig1–fig7`（论文用图）、
`example_traces.md`（B0 vs B4 执行轨迹叙事）。

## 模块结构

| 文件 | 职责 |
| --- | --- |
| `ibacsim/core.py` | 动作/授权契约 TAC/效果等数据模型；作用域模式匹配；按 (seed, kind, key) 定址的 RNG 流 |
| `ibacsim/world.py` | 模拟世界：文件系统/数据库/邮件/网络/记忆/凭据/子智能体 + 14 个工具 + 副作用日志 + 工具行为规约（behavior pinning） |
| `ibacsim/agent.py`（并入 runner） | Agent 执行策略：计划执行、注入采纳、拒绝后重试、连续 3 次拒绝后放弃 |
| `ibacsim/defenses.py` | B0 基线 / B1 内容检测器 / B2 沙箱 / B3 RBAC / B4 IBAC（含 provenance/attenuation/revocation/粒度开关、NL 委派变体） |
| `ibacsim/scenarios.py` | 攻击场景 A–H（安静/高噪双变体）+ 合法任务 L1–L11，全部带意图级 ground truth |
| `ibacsim/runner.py` | 试验执行引擎（升级审批的人类模型、旁路通道、工具内部效应调解、遏制与撤销传播计时） |
| `ibacsim/stats.py` | Bootstrap 置信区间、配对 Bootstrap 假设检验 |
| `ibacsim/plots.py` | 论文图表 |

## 实验设计与公平性声明

**指标（按论文 §7.4，修正了划分问题）**：每次未授权尝试的结局构成完全划分
{已阻断, 已执行, 未定}；UAR = 严重越权执行数/尝试数，ABR = 阻断数/尝试数，
二者不再存在交叉口径。LCR 在独立合法任务套件上测得。

**对照组的诚意设定**（避免"故意弱化对照组"）：
- B1 检测器看到的是任何模型侧检测器都能看到的全部信息：动作文本、参数、
  目标资源、操作类型。高噪攻击带有可识别的恶意 token（检测器可抓），安静
  攻击是措辞成常规业务步骤的范围越权（检测器**原理上**无法判定，因为授权
  不是内容属性）。召回率默认 0.8 并做了 0.5–0.95 扫描。
- B3 的角色是为"文档/报表"岗位按最小权限配置的：可读任意库表、可向任意
  地址发邮件、/docs 全读写、无库写、无凭据读取。其失误（一次性任务超出
  角色、角色内无法区分任务范围）是 RBAC 的结构性属性。
- B2 沙箱规则为静态环境级（目录白名单、出口白名单、代码黑名单），合法
  任务几乎不受影响（LCR 100%），但也看不见任务意图。
- B4 使用与 ground truth 同源的意图派生 TAC；它没有任何对 B0–B3 隐藏的信息
  优势，差异全部来自"授权对象绑定任务"这一机制本身。

**内部效度**：模型侧随机选择（注入采纳、重试、NL 遵守）由
(seed, kind, spec_id) 唯一决定，与控制面配置无关；控制面只能通过阻断
"投递动作"预防感染（单调包含检查），不能改变采纳概率本身。运行时自动
执行该检查并写入 summary.md。

**已知成本，如实报告**：B4 在攻击在场时的任务中止率约 33%（两次违规即撤销
全部能力——遏制机制的直接代价）；合法任务升级审批约 0.18 次/任务；残余
泄露约 0.5%（升级审批中 5% 人类误批的建模后果）。

## 效度边界

这是**机制级（in-silico）证据**：Agent 决策与人类审批为参数化概率模型。
它证明的是实验协议可执行、各机制在威胁模型内产生可测量的结构性差异，
**不能**替代真实 LLM 智能体/真实业务系统的实证。关键假设：①意图→TAC 推导
正确；②强制执行点覆盖全部副作用路径（H4 表明旁路存在时防护退化）；③人类
对恶意升级请求 95% 拒绝。

## 扩展钩子（通往真实实验）

- 把 `runner.run_actor` 中"采纳概率"换成真实 LLM 的注入成功率，工具层对接
  LangChain/MCP 的 hooks（或 OWASP ACS 拦截点），即可把 B4 控制面移植为
  真实系统的策略引擎；
- `scenarios.py` 中每个场景是声明式数据（计划 + 触发器 + 剧本 + 重试），
  新增场景无需改引擎；
- `STRIKE_LIMIT`（撤销阈值）、`NL_COMPLIANCE`、检测器召回/误报均为可扫参数。
