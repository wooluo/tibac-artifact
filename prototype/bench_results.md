# TIBAC 参考策略引擎：运行时开销基准

- 平台：macOS-15.7.7-arm64-arm-64bit | Python 3.11.9
- 工作负载：50,000 次裁决（60% 范围内放行 / 15% 越权拒绝 / 10% 已批汇点 / 10% 未批汇点拒绝 / 5% 租约过期拒绝），令牌 HMAC-SHA256 签名

## 每次工具调用的裁决开销（µs）

| 指标 | 裁决（含 HMAC 验签+作用域匹配） | 签发新能力令牌（租约更新） |
| --- | --- | --- |
| mean | 5.8 | 4.8 |
| p50 | 6.1 | 4.8 |
| p95 | 6.6 | 4.9 |
| p99 | 6.8 | 5.0 |
| max | 41.7 | 22.9 |

## 相对开销

| 基线场景 | TIBAC 裁决占比 |
| --- | --- |
| 快速内部 API 工具调用（50 ms） | 0.012% |
| 慢速外部 API / RPA 操作（500 ms） | 0.0012% |
| LLM 规划步（1.5 s） | 0.0004% |

**结论：** 参考实现（纯 Python、无缓存、无向量化）的单次裁决开销在数十微秒量级，相对任何真实工具调用（毫秒级起）或模型推理步（秒级）均 <0.2%，即强制授权的运行时代价可忽略；真正的成本在升级审批与撤销后的任务中断（见 `ibac_eval/results/summary.md` 第 5 节）。

**边界：** 这是参考实现的量级证据，不是生产性能调优结论；生产部署应使用常量时间比较、本地缓存热令牌的 MAC 验证、并预算原子计数器。
